# Horario Docentes — Node 24

Esta versión elimina `better-sqlite3`, que causaba el error de `node-gyp` con Node v24.

La información se guarda localmente en `backend/data.json`.

## IMPORTANTE
Reemplaza la carpeta anterior por esta versión.

En VS Code:
1. Abre la carpeta `backend`.
2. Ejecuta:
   `npm install`
3. Luego:
   `npm start`
4. Abre:
   `http://localhost:3000`
